# 图词对应优先的主题插画与页面填充

仅在主题已由用户选定或明确授权推荐、当前词表获明确确认后进入生图。缺主题先询问，缺词表确认先等待；按图片质量要求估计图数，与词表一起展示。用户明确设置预算时一并说明，不额外让使用者填表。

## 先确定质量要求，再优化成本

先检查用户提供的已有图册或图片中，是否有含义、主题和画风相符的插画。英文拼写相同但含义不同不能混用；真正读取旧素材后才算复用。保留正确的旧图，只为缺少插画的新词生成素材。没有已有素材时不声称已缓存或已复用。

在图词对应和清晰度满足要求时采用“插画素材总图”：把一组词的独立插画放在同一图片里，程序显示各词对应位置，再按一词一卡顺序呈现。每个词仍有自己的画面，合图不是让多个词共用同一角色或背景。学习页数不等于生图张数，不逐词或逐页调用生图，也不强求一张装下全课。

用户已选定四宫格作为默认产品规格：每张素材图两列两行、最多四词；网页每词一张卡片。普通四格素材优先用方形总图，让各格比例与最终显示相符；工具或画面需采用其他比例时，保留真实格位比例，不拉伸主体。词多分图分页，不足四词时未用格位留空，不加新词。复杂画面可少于四词或单独补图，不能为了填满四格删掉必要情境。除非用户明确改变规格，不采用六宫格、八宫格或额外生成密度样张。四格是产品选择，不是已证实的所有主题最佳容量；仍须逐图检查。

审核时说明按照质量要求预计的素材图数和单词卡片数，复杂词给少量画面例子。不预设整套1—2张或最多2次生成，完整范围需要几张就按需求规划。用户明确预算或实际免费额度触限时，再说明分批范围供其选择；未同意前不删词或执行缩减版。只生成所需成品，不生多张候选、额外封面、背景、角色肖像或风格样张。复用合适旧图、保留正确素材只修错图，不能以压低总图数替代这些成本优化。

免费额度的具体计量以用户当前产品界面为准，无法读取时标记未知，不编造免费次数；一张输出、一轮请求和一份额度并不必然相等。未经用户要求，不升级会员、购买额度或启用付费API。

## 先设计词义画面

内部为每个确认词确定“目标含义、必需主体或特征、动作／状态／关系线索、必要对象及参照、易混含义的可见差异”，只填写适用项目，不要求使用者填表。这些要求由当前词义推导，不能复制某次主题的角色姿势作为通用答案：

- 物品和动物等名词：突出可辨认的外形和类别特征，必要时交代组成或使用情境，不用无关道具代替目标主体。
- 动作词：明确谁在做什么、作用于什么对象，以及能看出正在发生该动作的姿态或接触关系。必要时保留环境参照；不能只有拿着道具而看不出目标动作。
- 状态、属性、位置及关系词：明确状态或关系本身，需要比较时保留相同尺度或稳定参照，不强行套成动作画面。
- 含义接近的词：在当前词表中成对检查，设计能看出的差异；不能只改变角色朝向、背景颜色或装饰就声称表达了不同词义。
- 难以直观表达的抽象词或短语：设计必要的小情境，利用已确认释义辅助理解；仍无法清楚表现时说明具体困难，不硬凑图标，不擅自增加英文例句或其他学习词。

动画角色用于参与这些词义情境，保持孩子喜欢的主题和正确物品特征；必要道具可以保留，不以“画面干净”为由删掉动作对象、参照或关键关系。

## 保留用户指定的动画与角色

在实际生图指令中明确写出用户选定的动画及角色名称，要求使用该动画中的原角色，再补充表达词义的动作、道具、场景与布局。准确、已核实的特征描述可以辅助识别，不能用泛泛描述替换具体角色，也不能自行设计外形或服装。仅在标题保留动画名也不够。

动画主题优先保留角色设计、辨识度及同一角色的跨格一致性。未指定改画风时采用与该动画相符的表现，不能将所有动画一律转成水彩／彩铅绘本。用户明确要求画风改造时可调整表现方式，但仍保留具体角色。普通场景主题可沿用默认手绘风格。

参考图是可选辅助，不默认要求家长找图，也不自动额外生成角色样张。已有合适参考且工具支持时可使用，实际传入后才能声称已参考。陌生或有歧义的角色先核实，仍不明确时只澄清必要信息；模型未能还原时如实标明主题缺项，不把普通同类形象算作成功。保留名称和设计约束能改进指令，但不保证一次生成成功。

## 真实生图与检查

检查任务实际能否调用图片生成并取得返回图片。skill不会自动授予权限或连接另一个聊天；能调用时按质量规划生成，遵守用户明确预算。不能调用或取不到原图时，说明缺项，给填好的生图指令，取得实际图片后再组装。不能把写提示词说成生图完成，不用代码SVG、CSS形状、emoji或占位图替代核心插画，除非用户明确同意。

普通场景素材图默认暖米白底、柔和手绘风格；动画主题遵守上面的角色与画风约定，不让默认风格覆盖用户选择。每格一个物品或小情境，主体完整且不跨格，没有任何教学文字。每格留少量安全边距即可，文字放在网页里小图下方，不必让图片浪费30%空间给文字。

动画主题可选汪汪队救援、海底小纵队探险、小猪佩奇家庭生活、布鲁伊游戏、哆啦A梦校园、冰雪奇缘冬季，也接受其他动画或角色。默认一套沿用一个动画总主题；选定角色参与部分词汇情境即可，不要求每格重复出现，不遮挡目标物品。角色及装饰不自动加入词表。

必须实际查看原图，按生成前确定的词义要求逐格核对：

1. 用户所选主题和角色是否可辨、同一角色是否一致；普通同类形象不能替代指定角色。
2. 目标主体、特征、动作／状态／关系及必要对象、参照是否实际可见；拿着道具或摆出泛泛姿势不等于词义已经表达。
3. 易混词是否有可见区别；临时遮住标签，画面是否能合理表示确认含义。无需猜出唯一英文词，也不要求抽象词脱离释义独立表达。
4. 肢体、物体形状、尺度及接触关系是否合理，有没有遮挡关键线索；数量、顺序、遗漏、重复和跨格是否正确。
5. 网页裁切后上述线索是否仍保留；原图合格但裁切后丢失关键对象仍需修正。

接口成功、格数正确、主题可辨与四格规格都不能替代这些检查。助手看图不能保证零漏错或已证实学习效果。

有错误时先标明具体格位、缺失或错误的线索及需要改变的内容，再按实际工具能力修正：显示或裁切偏差先改取图位置与排版；词义歧义、角色偏离或形体错误，工具支持局部编辑时修错误区域，否则单独生成该错词的替代小图，由模板映射替换。保留合格素材，不因一个错词重生整课。轻微装饰差异不重生，修复后重新检查原图和网页取图结果。重复返修无改善时停止原样重试，说明未解决项与调整办法；不以减少词数代替词义检查，不把明显错图或缺图充当完成品。遵守已有授权、用户明确预算及实际额度；图片编辑涉及生成时计入真实请求与消耗。完成后提供图册预览，只标出不确定之处，不让家长逐图填审核表或做技术操作。

这些规则适用于不同主题与词类；具体角色、动作姿态、必要道具和参照由当前任务确定。单次测试的角色、错误码或模型版本不成为全局要求。跨主题验证应使用不同主题及物品、动作、状态或关系等不同词类，检查能否从词义推导合适画面；未经实际测试，不声称通用效果已验证。规则本身不能保证模型一次生成正确。

## 素材总图生图指令

由助手填好实际主题、词义、格位和比例，不把方括号留给使用者。工具能真实接收且已取得前图时可用其作风格参考，不谎称未传入图片已作为参考。

```text
生成一张英语词汇图册用的主题插画素材总图，只要一张成品，不要多个候选。
统一主题：[用户选定的动画或场景主题]。
动画角色：[动画主题时明确填写动画作品及具体角色名称，要求使用原角色并保持既有设计与辨识度，只改变指定动作、道具和场景，同一角色各格一致；普通主题删除本行。补充描述不替代具体名称，不重新设计角色]。
布局：默认两列两行四宫格，整图比例为[实际确定的比例，普通四格优先1:1]，每格等宽等高，格位之间有干净安全边距，不画硬格线。最多四个词，未使用格位留空。每格一个完整物品或独立情境，不跨格、不遮挡相邻主体；保留表达含义所需的对象及参照。
按左到右、上到下严格绘制：[逐格填好目标含义、必需主体或特征、适用的动作／状态／关系线索、必要对象及参照、易混含义的可见区别]。每词配图与确认释义直接对应，肢体和物体形状、尺度及接触关系合理，关键线索清楚可见，不靠重复同一角色站姿或装饰物充当不同词的插画。
风格：[用户已指定的画风；未指定时，动画主题采用与该动画相符的表现并保留原角色设计，普通主题采用暖米白背景及柔和水彩／彩铅手绘]。主体形状清楚，整图风格一致；默认风格不覆盖所选角色。若为动画主题，让指定角色自然参与所需情境，不必每格出现，保留目标物品的可辨认性。
每格留少量空白边距，不需要文字留白区。不要画文字、英文、中文、数字标签、logo、标题或额外封面；不遗漏、交换或重复主体，不画通用emoji或几何图标代替物品。
```

一张图可以同时画同一总主题下的文具、颜色或食物等分组，网页再分别排页，不要求素材图本身就是最终学习页。

## 图片选项筛选与固定网页填充

先实际查看原图与裁切结果，再为每词挑合格错图池。错图应明确不符合该词当前含义；另一个词的图片可能也符合目标词，因此ID不同不代表错误。检查突出部位、动作执行者、对象、状态及关系；同义、并列含义、同场景也符合目标、重复以及靠风格露出答案的图都排除。具体配对、剔除理由及例外留在当前任务，不能把某次主题或词类写成全局禁用清单。

优先复用已有确认词库的配图，兼容的已审核旧课图片也可作为候选，错图不增加学习词表。不为每题额外生成四张图；只有确实缺少必要配图、用户已授权且预算允许时才补图。找不到三张明确错图时，该词保留英文朗读及翻页看图文的回想卡，交付说明具体原因，不强行做多答案题、不删词或填占位图。

复制assets/vocab-pages.html，复用脚本；只填标题、真实资源及词图映射。每张原图读为data URL，在head的style#atlas-resources保存一次，多个卡片和选项共用：

```css
:root { --atlas-1: url("data:image/png;base64,实际图片数据"); }
```

每词section.word-card含data-answer唯一词图标识、.question-face及默认hidden的.answer-face。题面英文button.word的data-say与显示英文一致。选择卡增加.choice-grid与p.choice-status；每个候选button.choice默认hidden，data-choice唯一，含aria-hidden=true的span.atlas-art及空span.choice-label。候选池必须有一个目标图及至少三张已筛选错图，脚本选三张错图、打乱四项并填字母A／B／C／D；选项无中文、英文词义标签、正确提示或描述答案的无障碍名称。

答案含h2.card-topic、默认hidden的p.answer-feedback、目标span.atlas-art（role=img，aria-label描述原图）及p.chinese。脚本在翻页后给当前题的选对／选错反馈；未选也可直接查看。回想卡不放.choice-grid或.choice-status，其余保持同一结构。首卡可见，其余section默认hidden。

每个候选插画和正确答案都用自己的真实图位：--atlas-image对应图片资源，--atlas-cols／--atlas-rows为实际列行数（四格2、2，单图1、1），--atlas-aspect保留格位宽高比。位置从0编号，x=列号/(列数-1)×100%，y=行号/(行数-1)×100%；维度1时该轴0%。计算与核对由助手处理，不让家长裁图或标坐标，不让所有选项继承正确图。

CSS只取真实图片，不绘制插画。查看裁切后完整主体、必要对象和参照，格位不规则或边距偏差时调整映射，不拉伸或裁掉语义。文字和属性做HTML转义，图片必须真实取得。图片题每卡四个选项是学习交互，素材每图四格是生成布局，两者数量无必然对应。

随机只在筛选后的池中抽取，正确图位置打乱；一轮打开中的选项固定，返回保留选择，刷新重新抽取。实际查看每题显示，确认没有因主体细节、风格、大小、标签或重复而露出答案，也不误把有语义重叠的图判错。自检与入口验证详见workflow.md。生成成功与程序只记录一个正确ID均不能证明语义唯一。
